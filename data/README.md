# Dataset

This folder contains the raw, processed, and submission datasets used in the Titanic Survival Prediction project.

## Dataset Source

The dataset was obtained from the Kaggle Titanic competition:

https://www.kaggle.com/c/titanic/data

## Directory Structure

```text
data/
│
├── raw/
│   ├── train.csv
│   └── test.csv
│
├── processed/
│   ├── train_processed.csv
│   └── test_processed.csv
│
├── submission/
│   └── predictions.csv
│
└── README.md
```

## Raw Data

### `raw/train.csv`

The original training dataset provided by Kaggle.

It contains passenger information and the `Survived` target variable.

### `raw/test.csv`

The original test dataset provided by Kaggle.

It contains passenger information but does not contain the `Survived` target variable.

## Processed Data

The preprocessing steps are implemented in:

```text
src/preprocessing.py
```

The processed datasets are generated using the preprocessing pipeline and saved separately:

* `train_processed.csv`
* `test_processed.csv`

The processed datasets are used in the model training and prediction stages.

## Submission Data

The final predictions generated by the trained model are stored in:

```text
data/submission/predictions.csv
```

The `predictions.csv` file contains:

* `PassengerId` — unique passenger identifier
* `Survived` — predicted survival outcome (`0 = No`, `1 = Yes`)

This file is generated after the prediction stage and is formatted for submission to the Kaggle Titanic competition.

## Data Workflow

```text
raw/train.csv
      ↓
Preprocessing
      ↓
processed/train_processed.csv
      ↓
Model Training
      ↓
model.pkl


raw/test.csv
      ↓
Preprocessing
      ↓
processed/test_processed.csv
      ↓
Prediction
      ↓
submission/predictions.csv
```
